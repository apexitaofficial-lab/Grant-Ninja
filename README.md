# Grant Ninja

## Overview

Grant Ninja is an AI-powered research grants discovery platform designed to become the world's most extensive research grants database.

The platform automatically discovers, extracts, classifies and publishes grants from government websites using AI.

This repository contains

- Next.js Website
- Python AI Pipeline
- Supabase Database
- Admin Dashboard
- SEO Engine
- AI Knowledge Graph
